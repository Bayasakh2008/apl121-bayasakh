13. Өвлийн хүйтэн
7 хоногийн температурыг (°C) оруулж, °F руу хөрвүүлээд хүйтний ангилал болон хувцасны зөвлөмж гаргаж, хамгийн хүйтэн өдрийг олно.
# Жишээ гаралт
Оролт: 5, -10, -20, -35, -2, -28, 0

1-r udur: 5.0C=41.0F, Dulaan, Nimgen, hungun huvtsas
2-r udur: -10.0C=14.0F, Huiten, Nimgen kurtik
3-r udur: -20.0C=-4.0F, Mash huiten, Zuzaan kurtik, malgai, oroolt, beelii
4-r udur: -35.0C=-31.0F, Tas huiten, Mash zuzaan huvtsas
5-r udur: -2.0C=28.4F, Huiten, Nimgen kurtik
6-r udur: -28.0C=-18.4F, Mash huiten, Zuzaan kurtik, malgai, oroolt, beelii
7-r udur: 0.0C=32.0F, Dulaan, Nimgen, hungun huvtsas
Hamgiin huiten udur: 4-r udur, -35.0C

## Өөрийн тогтоосон дүрмүүд
- Хүйтний ангилал: c >= 0 Dulaan, c >= -15 Huiten, c >= -3` Mash huiten, бусад нь Tas huiten.
- Фаренгейт: f = c * 1.8 + 32.
- minC-ийг эхэндээ 100 гэж авсан. Ингэснээр эхний өдрийн температур заавал minC-ээс бага болж, өвлөөс өөр температурт ч зөв ажиллана.
- Хоёр өдөр ижил температуртай бол эхний өдрийг хамгийн хүйтэн гэж үзнэ (c < minC).
